Пономаренко Никита Александрович


Розовый трекер привычек — небольшое приложение для поддержки регулярных действий. Логика простая: завёл привычку, каждый день отмечаешь, выполнил ли её, и смотришь на результат. Без наград и сложных целей — только честная статистика, которая помогает держать ритм.

**Что умеет**

- Просмотр списка привычек с отметкой о выполнении на текущий день и сводкой по числу закрытых задач.
- Создание привычек с валидацией полей (название — обязательное, до 50 символов; описание — необязательное, до 200).
- Изменение данных привычки и её удаление — вместе с удалением всех накопленных отметок.
- Экран статистики за последнюю неделю: видно, в какие дни был прогресс, и общее число выполненных отметок.
- Удобная тёмная тема с розовыми акцентами.

**Технологическая часть**

- Язык: Dart.
- Фреймворк: Flutter (Material 3).
- База: SQLite (`sqflite`), а для запуска на десктопе — `sqflite_common_ffi`.
- Перечень платформ: Android, iOS, web, Windows, macOS, Linux.
- Хранение локальное, сервер не требуется.
